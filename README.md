# Erste Runde

Das Kartenspiel zum Kennenlernen. Läuft im Browser auf Handy, Tablet und PC.

**Spielen:** https://kwormsbecher-alt.github.io/erste-runde/

## Aktualisieren
1. Neue Version als `index.html` speichern.
2. Hier im Repo: **Add file → Upload files**, Datei reinziehen, **Commit changes**.
3. Nach 1–2 Minuten ist die neue Version online.

Eigene Karten stehen in `index.html` im Block **MEINE KARTEN** (nach `✏️ THEMA` suchen).
